# Face Recognition from Partial Face

Experiment code behind the presentation. Pipeline: LFW → MTCNN detection + 5-point alignment →
partial-face variants → frozen VGG-Face / FaceNet features → Softmax classifier.

Slides: [slides/Partial_Face_Recognition.pdf](slides/Partial_Face_Recognition.pdf) ·
Current LFW results: [results/RESULTS.md](results/RESULTS.md) (regenerated by step 4)

```
photo ─► MTCNN (box + 5 landmarks) ─► align to 224×224 ─► occlusion variant (7) ─► VGG-Face fc7 / FaceNet (frozen)
      ─► Softmax ─► name + probability p ─► p < τ (0.5) ? "Unknown" : name
```

## Setup

```bash
pip install -r requirements.txt
pip install --no-deps facenet-pytorch==2.6.0     # its own pins would downgrade torch/numpy
cd src
python download_data.py                          # LFW + FEI from Kaggle, VGG-Face weights from GitHub
```

`download_data.py` needs `kagglehub` (in requirements) and, if Kaggle asks for a login, an API token
(kaggle.com → Settings → API → Create New Token → `~/.kaggle/kaggle.json`). Manual download also works:

| What | Source | Put it in |
|---|---|---|
| LFW | [kaggle.com/datasets/jessicali9530/lfw-dataset](https://www.kaggle.com/datasets/jessicali9530/lfw-dataset) (or scikit-learn's `fetch_lfw_people`) | `data/lfw/` (or `data/lfw_home/lfw/`) |
| FEI Face Database | [kaggle.com/datasets/whizzkid/fei-face-data](https://www.kaggle.com/datasets/whizzkid/fei-face-data) | `data/fei/` (any depth; original `1-01.jpg … 200-14.jpg` names) |
| Custom (group members) | `python capture_faces.py --name <Name>` or your own photos | `data/custom/<Name>/*.jpg` |
| VGG-Face weights | [rcmalli/keras-vggface v2.0](https://github.com/rcmalli/keras-vggface/releases/tag/v2.0) `rcmalli_vggface_tf_vgg16.h5` | `weights/` |

FaceNet and MTCNN weights ship with facenet-pytorch. If both `data/lfw_home/lfw` and `data/lfw/` exist,
step 1 uses `data/lfw_home/lfw`, the copy the slide numbers were measured on.

## Run the experiment

Every step takes `--dataset lfw` (default), `fei`, `custom`, or a combination such as `lfw+custom`.
LFW writes to `results/`, the others to `results/<dataset>/`.

```bash
cd src
python step1_detect_align.py                # pick people (LFW: >= 20 images, max 50), MTCNN + align -> faces.npz
python step2_extract_features.py            # 7 variants x {VGG-Face, FaceNet} features      -> features_*.npz
python step3_train_evaluate.py              # train M0-M4, test every variant, check T1-T3     -> metrics.json, models/
python step4_figures.py                     # figures + RESULTS.md

python step3_train_evaluate.py --seeds 0 1 2 3 4    # optional: mean ± std over 5 more random 70/30 splits

# FEI: same steps; step 4 adds pose_fei.png (accuracy and MTCNN detection rate at each of the 14 poses)
python step1_detect_align.py --dataset fei && python step2_extract_features.py --dataset fei
python step3_train_evaluate.py --dataset fei && python step4_figures.py --dataset fei
```

| Method | Features | Trained on |
|---|---|---|
| M0 | Eigenfaces (PCA 150) + SVM | full faces (classical baseline) |
| M1 | VGG-Face fc7 + Softmax | full faces only — training (ก) |
| M2 | VGG-Face fc7 + Softmax | full + 6 partial variants — training (ข) |
| M3 | FaceNet (VGGFace2) + Softmax | full faces only |
| M4 | FaceNet (VGGFace2) + Softmax | full + 6 partial variants |

Step 3 writes, per dataset:

- `metrics.json` — accuracy, macro precision / recall / F1, ROC-AUC (OvR), top-5, coverage@τ and accuracy@τ
- `targets.json` — T1 (full ≥ 95 %), T2 (mask / sunglasses ≥ 85 %), T3 (M2 − M1 ≥ +10 points on M1's worst variant)
- `predictions.csv` — every test image × method × variant: true name, prediction, confidence, accepted at τ
- `top_confusions.csv` — the most frequent wrong (true → predicted) pairs
- `metrics_seeds.json` — with `--seeds`
- `models/<dataset>_M1..M4.joblib` — the trained classifiers. `--fit-all` refits them on every image (use it for the live demo)

## Use the model

```bash
cd src
python predict.py photo.jpg                          # every face: name / "Unknown", p, top-5; annotated copy in results/predict/
python predict.py photos/ --variant mask --tau 0.6   # simulate a mask, stricter threshold
python webcam.py                                     # live: v = next occlusion, +/- = tau, s = save, q = quit
cd .. && streamlit run app.py                        # web demo: upload or camera, choose model, occlusion and tau
```

All three default to `models/lfw_M2.joblib`; pass `--model ../models/<file>.joblib` for another one.

**Recognising the group members** (slide 6, Custom Dataset): record 30-40 photos per person in several
lighting conditions and head angles, then train and run the webcam on that model:

```bash
cd src
python capture_faces.py --name Worasak               # SPACE = start/pause, q = quit; repeat for each member
python step1_detect_align.py --dataset lfw+custom     # or --dataset custom for the members only
python step2_extract_features.py --dataset lfw+custom
python step3_train_evaluate.py --dataset lfw+custom --fit-all
python webcam.py --model ../models/lfw+custom_M2.joblib
```

Use plain English folder names: they are the labels OpenCV draws.

## Results (LFW, 62 people, 2,063 faces, test = 30 %)

Accuracy (%) from [results/metrics.json](results/metrics.json):

| Test variant | M0 | M1 | M2 | M3 | M4 |
|---|---:|---:|---:|---:|---:|
| full | 59.5* | 99.7 | 99.8 | 99.8 | 99.7 |
| upper_half | 7.0* | 90.8 | 98.4 | 94.7 | 97.7 |
| lower_half | 4.0* | 36.7 | 85.1 | 60.9 | 88.7 |
| eyes_only | 2.4* | 44.6 | 91.1 | 69.1 | 93.2 |
| nose_mouth | 1.1* | 36.7 | 89.3 | 55.4 | 91.6 |
| mask | 5.7* | 85.3 | 97.2 | 93.5 | 97.7 |
| sunglasses | 6.6* | 77.9 | 94.8 | 89.0 | 97.7 |

T1 99.8 % ≥ 95 · T2 97.2 / 94.8 % ≥ 85 · T3 nose_mouth 36.7 → 89.3 (+52.7) and lower_half 36.7 → 85.1 (+48.5) ≥ +10.

\* M0 was scored with the argmax of SVC's Platt-scaled `predict_proba`, which can disagree with the SVM's
own prediction. Step 3 now scores M0 with the SVM decision values (argmax = `predict`), so re-running
step 3 will change the M0 column; M1-M4 are unaffected.

## Layout

```
src/common.py                 settings, dataset finders, alignment template, occlusion variants
src/vggface.py                VGG-Face (VGG-16) in PyTorch, loads keras-vggface weights
src/backbones.py              frozen VGG-Face / FaceNet feature extractors
src/download_data.py          Kaggle datasets + VGG-Face weights
src/step1_detect_align.py     pick identities, MTCNN detect + align -> faces.npz
src/step2_extract_features.py build 7 variants, extract features -> features_*.npz
src/step3_train_evaluate.py   train M0-M4, evaluate per variant, save models -> metrics.json, models/
src/step4_figures.py          figures and RESULTS.md for the slides -> results/figures/*.png
src/recognizer.py             detect -> align -> features -> Softmax -> name or "Unknown" for new images
src/predict.py                recognise faces in photos
src/webcam.py                 live recognition from a webcam
src/capture_faces.py          record webcam photos for the custom dataset
app.py                        Streamlit demo
data/      datasets (not in git)       weights/  VGG-Face weights (not in git)
results/   metrics, predictions, figures (LFW; other datasets in results/<dataset>/)
models/    trained Softmax classifiers (*.joblib, ~2 MB for VGG-Face)
```
