# Face Recognition from Partial Face

Experiment code behind the presentation. Pipeline: LFW → MTCNN detection + 5-point alignment →
partial-face variants → frozen VGG-Face / FaceNet features → Softmax classifier.

Slides: [slides/Partial_Face_Recognition.pdf](slides/Partial_Face_Recognition.pdf) ·
Current LFW results: [results/RESULTS.md](results/RESULTS.md) (regenerated by step 4)

🇹🇭 **ภาษาไทย:** คำอธิบายทั้งหมดเป็นภาษาไทยอยู่ท้ายไฟล์นี้ → [คำอธิบายภาษาไทย](#คำอธิบายภาษาไทย)

```
photo ─► MTCNN (box + 5 landmarks) ─► align to 224×224 ─► occlusion variant (7) ─► VGG-Face fc7 / FaceNet (frozen)
      ─► Softmax ─► name + probability p ─► p < τ (0.5) ? "Unknown" : name
```

## Setup

```bash
pip install -r requirements.txt
pip install --no-deps facenet-pytorch==2.6.0     # its own pins would downgrade torch/numpy
cd src
python download_data.py                          # LFW + FEI from Kaggle, VGG-Face weights from GitHub
```

`download_data.py` needs `kagglehub` (in requirements) and, if Kaggle asks for a login, an API token
(kaggle.com → Settings → API → Create New Token → `~/.kaggle/kaggle.json`). Manual download also works:

| What | Source | Put it in |
|---|---|---|
| LFW | [kaggle.com/datasets/jessicali9530/lfw-dataset](https://www.kaggle.com/datasets/jessicali9530/lfw-dataset) (or scikit-learn's `fetch_lfw_people`) | `data/lfw/` (or `data/lfw_home/lfw/`) |
| FEI Face Database | [kaggle.com/datasets/whizzkid/fei-face-data](https://www.kaggle.com/datasets/whizzkid/fei-face-data) | `data/fei/` (any depth; original `1-01.jpg … 200-14.jpg` names) |
| Custom (group members) | `python capture_faces.py --name <Name>` or your own photos | `data/custom/<Name>/<session>/*.jpg` |
| Strangers (optional) | `python capture_faces.py --name <Name> --stranger`: people outside the group | `data/unknown/` |
| VGG-Face weights | [rcmalli/keras-vggface v2.0](https://github.com/rcmalli/keras-vggface/releases/tag/v2.0) `rcmalli_vggface_tf_vgg16.h5` | `weights/` |

FaceNet and MTCNN weights ship with facenet-pytorch. If both `data/lfw_home/lfw` and `data/lfw/` exist,
step 1 uses `data/lfw_home/lfw`, the copy the slide numbers were measured on.

## Run the experiment

Every step takes `--dataset lfw` (default), `fei`, `custom`, or a combination such as `lfw+custom`.
LFW writes to `results/`, the others to `results/<dataset>/`.

**How the test set is chosen.** This is closed-set identification: every person must be in both the training
and the test set, but no photo may be in both (its occluded copies stay on the same side). LFW and FEI use a
70/30 split of the images, stratified by person. Webcam frames from one recording are near-duplicates, so a
custom person recorded in two or more sessions keeps one whole session as test data instead.

**Strangers (open-set test).** Step 1 also builds `unknown.npz`: up to 500 LFW people who are *not* classes of
the dataset (one photo each) plus every photo in `data/unknown/`. They are never trained on; step 3 counts how
many of them still get a name instead of "Unknown" at each τ and reports the τ that keeps this at ≤ 5 %.

```bash
cd src
python step1_detect_align.py                # pick people (LFW: >= 20 images, max 50), MTCNN + align -> faces.npz
python step2_extract_features.py            # 7 variants x {VGG-Face, FaceNet} features      -> features_*.npz
python step3_train_evaluate.py              # train M0-M4, test every variant, check T1-T3     -> metrics.json, models/
python step4_figures.py                     # figures + RESULTS.md

python step3_train_evaluate.py --seeds 0 1 2 3 4    # optional: mean ± std over 5 more random 70/30 splits

# data augmentation (slide 6): 2 random copies of every face -> step 3 adds M1+aug ... M4+aug
python step2_extract_features.py --augment 2 && python step3_train_evaluate.py && python step4_figures.py

# already have faces.npz and features from an earlier run? add only the strangers:
python step1_detect_align.py --strangers-only && python step2_extract_features.py   # step 2 skips up-to-date files
python step3_train_evaluate.py && python step4_figures.py

# FEI: same steps; step 4 adds pose_fei.png (accuracy and MTCNN detection rate at each of the 14 poses)
python step1_detect_align.py --dataset fei && python step2_extract_features.py --dataset fei
python step3_train_evaluate.py --dataset fei && python step4_figures.py --dataset fei
```

| Method | Features | Trained on |
|---|---|---|
| M0 | Eigenfaces (PCA 150) + SVM | full faces (classical baseline) |
| M1 | VGG-Face fc7 + Softmax | full faces only — training (ก) |
| M2 | VGG-Face fc7 + Softmax | full + 6 partial variants — training (ข) |
| M3 | FaceNet (VGGFace2) + Softmax | full faces only |
| M4 | FaceNet (VGGFace2) + Softmax | full + 6 partial variants |
| M1+aug … M4+aug | same as M1 … M4 | plus K augmented copies of every *training* image (step 2 `--augment K`) |

**Data augmentation** (slide 6, `common.augment`): each copy of an aligned face is rotated by up to ±15°, randomly
cropped (zoom up to 15 %, shift up to 5 %), flipped left-right half of the time, given new brightness and contrast
and a little camera noise; the occlusion is applied afterwards, so the mask or glasses land slightly off the
template as real ones do. Step 2 makes the copies for every face, but step 3 trains only on the copies of its
training images and always tests on the original, un-augmented test images, so nothing leaks. Step 4 draws
`augmentation.png` (examples for the slide) and `augmentation_effect.png`, and RESULTS.md gets a with/without
table. Copies multiply step 2's time by K (a CUDA GPU is used automatically when present); K = 2 suits LFW,
K = 5 a small custom set.

Step 3 writes, per dataset:

- `metrics.json` — accuracy, macro precision / recall / F1, ROC-AUC (OvR), top-5, coverage@τ and accuracy@τ
- `targets.json` — T1 (full ≥ 95 %), T2 (mask / sunglasses ≥ 85 %), T3 (M2 − M1 ≥ +10 points on M1's worst variant)
- `predictions.csv` — every test image × method × variant: true name, prediction, confidence, accepted at τ
- `top_confusions.csv` — the most frequent wrong (true → predicted) pairs
- `open_set.json` — over τ: known test faces given the right name / a wrong name / "Unknown", and strangers given
  a name (step 4 draws it as `open_set_M2.png` and adds a table to RESULTS.md)
- `metrics_seeds.json` — with `--seeds`
- `models/<dataset>_M1..M4.joblib` — the trained classifiers. `--fit-all` refits them on every image (use it for the live demo)

## Use the model

```bash
cd src
python predict.py photo.jpg                          # every face: name / "Unknown", p, top-5; annotated copy in results/predict/
python predict.py photos/ --variant mask --tau 0.6   # simulate a mask, stricter threshold
python webcam.py                                     # live: v = next occlusion, +/- = tau, s = save, q = quit
cd .. && streamlit run app.py                        # web demo: upload or camera, choose model, occlusion and tau
```

All three default to `models/lfw_M2.joblib`; pass `--model ../models/<file>.joblib` for another one.

**Recognising the group members** (slide 6, Custom Dataset): record 30-40 photos per person in at least two
sessions (another day, room or lighting) so that step 3 can test on a session the model never saw. Record a few
people outside the group with `--stranger` to see how often a stranger gets a member's name:

```bash
cd src
python capture_faces.py --name Worasak                    # SPACE = start/pause, q = quit -> data/custom/Worasak/<date>/
python capture_faces.py --name Worasak --session lamp     # second session, other lighting
python capture_faces.py --name Somchai --stranger         # not a member -> data/unknown/Somchai/<date>/
python step1_detect_align.py --dataset lfw+custom     # or --dataset custom for the members only
python step2_extract_features.py --dataset lfw+custom --augment 2   # K copies of every face, LFW too: slow on CPU
python step3_train_evaluate.py --dataset lfw+custom --fit-all
python webcam.py --model "../models/lfw+custom_M2+aug.joblib"
```

Use plain English folder names: they are the labels OpenCV draws. With only 5 members the Softmax always picks
one of the 5, so a stranger gets a member's name unless τ is high enough: use the τ step 3 prints
(`predict.py`/`webcam.py --tau`; the app shows it in the sidebar).

## Results (LFW, 62 people, 2,063 faces, test = 30 %)

Accuracy (%) from [results/metrics.json](results/metrics.json):

| Test variant | M0 | M1 | M2 | M3 | M4 |
|---|---:|---:|---:|---:|---:|
| full | 59.5* | 99.7 | 99.8 | 99.8 | 99.7 |
| upper_half | 6.9* | 90.8 | 98.4 | 94.7 | 97.7 |
| lower_half | 4.0* | 36.7 | 85.1 | 60.9 | 88.7 |
| eyes_only | 2.4* | 44.6 | 91.1 | 69.1 | 93.2 |
| nose_mouth | 1.1* | 36.7 | 89.3 | 55.4 | 91.6 |
| mask | 5.7* | 85.3 | 97.3 | 93.5 | 97.7 |
| sunglasses | 6.6* | 77.9 | 94.8 | 89.0 | 97.7 |

T1 99.8 % ≥ 95 · T2 97.3 / 94.8 % ≥ 85 · T3 nose_mouth 36.7 → 89.3 (+52.7) and lower_half 36.7 → 85.1 (+48.5) ≥ +10.

\* M0 was scored with the argmax of SVC's Platt-scaled `predict_proba`, which can disagree with the SVM's
own prediction. Step 3 now scores M0 with the SVM decision values (argmax = `predict`), so re-running
step 3 will change the M0 column; M1-M4 are unaffected.

## คำอธิบายภาษาไทย

ส่วนบนของไฟล์นี้เป็นภาษาอังกฤษ ส่วนนี้อธิบายเนื้อหาเดียวกันเป็นภาษาไทย พร้อมคำสั่งที่ใช้บ่อย

### โปรเจกต์นี้ทำอะไร

ระบบระบุตัวบุคคลจาก **ภาพใบหน้าที่ถูกบดบังบางส่วน** (Occlusion) เช่น สวมหน้ากากอนามัย แว่นกันแดด หรือเห็นแค่
ครึ่งบน/ครึ่งล่างของใบหน้า งานนี้เป็นแบบ *closed-set identification* คือระบบรู้จักเฉพาะกลุ่มคนที่ใช้เทรน แล้วทายว่า
ภาพใหม่เป็นใครในกลุ่มนั้น และตอบ **"ไม่รู้จัก" (Unknown)** เมื่อความมั่นใจต่ำกว่าเกณฑ์ τ

ใช้ Transfer Learning: นำโมเดลที่เทรนกับใบหน้าจำนวนมากมาแล้ว (VGG-Face หรือ FaceNet) มาเป็นตัวสกัดคุณลักษณะ
(Feature Extractor) โดย **ไม่ปรับน้ำหนักของโมเดลนั้น** แล้วเทรนเฉพาะชั้นจำแนกสุดท้าย (Softmax) ด้วยข้อมูลของเราเอง
ชั้นนี้ใช้ `LogisticRegression` ของ scikit-learn (แบบ multinomial ซึ่งก็คือ Softmax)

### ขั้นตอนการทำงานของระบบ

```
ภาพ ─► MTCNN (กรอบหน้า + 5 จุด) ─► จัดตำแหน่งเป็น 224×224 ─► จำลองการบดบัง (7 แบบ)
    ─► VGG-Face fc7 / FaceNet (แช่แข็ง) ─► Softmax ─► ชื่อ + ความน่าจะเป็น p ─► p < τ (0.5) ? "Unknown" : ชื่อ
```

| ขั้นตอน | ทำอะไร |
|---|---|
| MTCNN | ตรวจจับใบหน้า ได้กรอบหน้าและจุด landmark 5 จุด (ตาซ้าย ตาขวา ปลายจมูก มุมปากซ้าย มุมปากขวา) |
| Alignment | หมุนและย่อ/ขยายภาพให้ 5 จุดตรงกับแม่แบบ ได้ภาพ 224×224 ทำให้ทุกภาพมีตา จมูก ปาก อยู่ตำแหน่งเดียวกัน กล่องที่ใช้บดบังจึงตกที่ส่วนเดียวกันเสมอ และเทียบข้ามคนได้ยุติธรรม |
| จำลองการบดบัง | ปิดหรือเหลือบางส่วนของภาพที่จัดตำแหน่งแล้ว มี 7 รูปแบบ (ตารางด้านล่าง) |
| สกัด Feature | VGG-Face (ชั้น fc7, 4,096 มิติ) หรือ FaceNet (VGGFace2, 512 มิติ) |
| Softmax | ให้ความน่าจะเป็นของแต่ละคน เลือกคนที่ p สูงสุด ถ้า p ต่ำกว่า τ ตอบ "Unknown" |

รูปแบบการบดบัง 7 แบบ (พิกัดบนภาพ 224×224 เป็น `(x0, y0, x1, y1)` นิยามอยู่ใน `src/common.py`):

| ชื่อในโค้ด | ภาษาไทย | สิ่งที่เหลือให้เห็น |
|---|---|---|
| `full` | ใบหน้าเต็ม | ทั้งใบหน้า (ใช้เป็นค่าอ้างอิง) |
| `upper_half` | ครึ่งบน | แถว y 0–124 (ตา คิ้ว หน้าผาก) |
| `lower_half` | ครึ่งล่าง | แถว y 124–224 (ปลายจมูก ปาก คาง) |
| `eyes_only` | เฉพาะดวงตา | กล่อง (30, 66, 194, 120) |
| `nose_mouth` | เฉพาะจมูก+ปาก | กล่อง (56, 108, 168, 192) |
| `mask` | สวมหน้ากากอนามัย | ปิดกล่อง (24, 116, 200, 224) ตั้งแต่จมูกลงไป |
| `sunglasses` | สวมแว่นกันแดด | ปิดกล่อง (44, 72, 180, 116) ทับดวงตาทั้งสอง |

### ติดตั้ง

```bash
pip install -r requirements.txt
pip install --no-deps facenet-pytorch==2.6.0     # ถ้าไม่ใส่ --no-deps มันจะลดเวอร์ชัน torch/numpy ของเรา
```

  จะเปิดหน้าต่างภาพไม่ได้
- น้ำหนักของ FaceNet และ MTCNN มากับ facenet-pytorch ไม่ต้องโหลดเพิ่ม

```bash
python step4_figures.py               # สร้างกราฟและ RESULTS.md ไว้ใส่สไลด์          -> results/figures/
```

| 4 | วาดกราฟและเขียนสรุปผล | `results/figures/*.png`, `RESULTS.md` |

### โมเดลที่เปรียบเทียบ

| โมเดล | Feature | เทรนด้วย |
|---|---|---|
| M0 | Eigenfaces (PCA 150) + SVM | ภาพเต็ม (Baseline แบบดั้งเดิม) |
| M1 | VGG-Face fc7 + Softmax | ภาพเต็มอย่างเดียว (แบบ ก) |
| M2 | VGG-Face fc7 + Softmax | ภาพเต็ม + ภาพบดบังอีก 6 แบบ (แบบ ข) |
| M3 | FaceNet (VGGFace2) + Softmax | ภาพเต็มอย่างเดียว |
| M4 | FaceNet (VGGFace2) + Softmax | ภาพเต็ม + ภาพบดบังอีก 6 แบบ |
| M1+aug … M4+aug | เหมือน M1 … M4 | เพิ่มสำเนา Augmentation ของภาพชุดเทรนอีก K ชุด |

เป้าหมายในสไลด์หน้า 5 และวิธีตรวจ (step 3 เขียนลง `targets.json` ให้อัตโนมัติ):

- **T1:** Accuracy ของ M2 บนใบหน้าเต็ม ≥ 95 %
- **T2:** Accuracy ของ M2 เมื่อสวมหน้ากากและเมื่อสวมแว่น ≥ 85 % ทั้งคู่
- **T3:** M2 ดีกว่า M1 อย่างน้อย +10 จุด บนรูปแบบที่ M1 ได้ต่ำที่สุด (ถ้าต่ำสุดเท่ากันหลายแบบ จะรายงานทุกแบบ)

### วิธีเลือกชุดทดสอบ (สำคัญ)

งานนี้เป็น closed-set identification ดังนั้น

- **ทุกคนต้องอยู่ทั้งชุดเทรนและชุดทดสอบ** (ไม่ใช่แบ่งตามคน เพราะคนที่อยู่ชุดทดสอบอย่างเดียวจะไม่มีคลาสให้ทาย)
- **ภาพเดียวกันห้ามอยู่ทั้งสองชุด** รวมถึงภาพที่ปิดบังหรือภาพ augment ที่สร้างมาจากภาพนั้นด้วย
- LFW และ FEI แบ่ง 70/30 ตามภาพ แบบ stratified (สัดส่วนต่อคนเท่ากัน) ด้วย seed 42
- **ข้อมูลที่ถ่ายจากเว็บแคม:** ภาพที่ถ่ายต่อเนื่องในรอบเดียวแทบเหมือนกัน ถ้าสุ่มแบ่งภาพจะข้ามฝั่งกัน และ Accuracy จะสูงเกินจริง
  ดังนั้นถ้าคนไหนถ่ายตั้งแต่ 2 รอบ (session) ขึ้นไป step 3 จะเก็บ **ทั้งรอบ** ไว้เป็นชุดทดสอบ ส่วนคนที่มีรอบเดียวจะแบ่ง 70/30
  ตามปกติ พร้อมเตือนว่าผลอาจสูงเกินจริง

### Data Augmentation

สร้างสำเนาสุ่มของภาพชุดเทรนเพื่อเพิ่มความหลากหลาย (สไลด์หน้า 6) แต่ละสำเนาจะถูก

1. หมุนไม่เกิน ±15°
2. ครอบตัดแบบสุ่ม (ซูมเข้าไม่เกิน 15 % เลื่อนไม่เกิน 5 %)
3. พลิกซ้าย–ขวา (สุ่ม 50 %)
4. ปรับความสว่างและคอนทราสต์
5. เติมสัญญาณรบกวนเล็กน้อย

แล้วจึงจำลองการบดบังทีหลัง ทำให้หน้ากากหรือแว่นเลื่อนจากตำแหน่งมาตรฐานเล็กน้อยเหมือนของจริง

- ใช้ `python step2_extract_features.py --augment K` เพื่อสร้างสำเนา K ชุด (LFW แนะนำ K = 2, ชุดสมาชิกกลุ่มที่ภาพน้อยแนะนำ K = 5)
- step 2 สร้างสำเนาให้ทุกภาพ แต่ step 3 เทรนเฉพาะสำเนาของ **ภาพชุดเทรน** และทดสอบกับภาพทดสอบต้นฉบับที่ไม่ผ่าน augment เสมอ
  จึงไม่มีข้อมูลรั่ว
- step 3 จะเพิ่มโมเดล `M1+aug … M4+aug` ให้เปรียบเทียบ ส่วน step 4 วาด `augmentation.png` (ตัวอย่างสำหรับใส่สไลด์) และ
  `augmentation_effect.png` (เทียบมี/ไม่มี augmentation) พร้อมตารางใน `RESULTS.md`
- เวลาสกัด feature จะเพิ่มตามจำนวนสำเนา K ถ้าเครื่องมี GPU (CUDA) โค้ดจะใช้ให้อัตโนมัติ

### ทดสอบกับคนแปลกหน้า และการตั้งค่า τ

โมเดล Softmax ต้องเลือกหนึ่งในคนที่รู้จักเสมอ คนแปลกหน้าจึงอาจถูกทายเป็นชื่อคนในกลุ่มด้วยความมั่นใจสูง
(โดยเฉพาะกลุ่มที่มีแค่ 5 คน) ทางแก้คือตั้งเกณฑ์ **τ** ให้เหมาะ:

- step 1 สร้าง `unknown.npz` จากคนใน LFW ที่ **ไม่ได้เป็นคลาสของชุดนั้น** สูงสุด 500 คน (คนละ 1 ภาพ) รวมกับภาพทุกภาพใน
  `data/unknown/` คนเหล่านี้ไม่ถูกใช้เทรนเลย
- step 3 นับว่าที่ τ แต่ละค่า มีคนแปลกหน้ากี่ % ที่ยังถูกตอบเป็นชื่อ (แทนที่จะเป็น "Unknown") และบอกค่า τ ที่ทำให้
  ตัวเลขนี้ **ไม่เกิน 5 %** ผลอยู่ใน `open_set.json`, กราฟ `open_set_M2.png` และตารางใน `RESULTS.md`
- ค่า τ ที่แนะนำจะถูกเก็บไว้ในไฟล์โมเดล `predict.py` และแอปจะแสดงให้เห็น ปรับใช้ได้ด้วย `--tau` หรือแถบเลื่อนในแอป
- ยิ่งตั้ง τ สูง คนแปลกหน้าหลุดผ่านน้อยลง แต่ภาพของคนที่รู้จักก็จะถูกตอบว่า "Unknown" มากขึ้นด้วย
  ในกราฟ `open_set_M2.png` ดูจุดสมดุลได้

### ใช้โมเดลกับภาพใหม่

ต้องรัน step 1–3 ก่อน เพื่อให้มีโฟลเดอร์ `models/` (ค่าเริ่มต้นคือ `models/lfw_M2.joblib`)

```bash
cd src
python predict.py photo.jpg                          # ทายทุกใบหน้าในรูป: ชื่อ / "Unknown", p, Top-5 และบันทึกรูปที่ใส่กรอบไว้ใน results/predict/
python predict.py photos/ --variant mask --tau 0.6   # ทั้งโฟลเดอร์, จำลองใส่หน้ากาก, ตั้ง τ = 0.6
python webcam.py                                     # ทายสดจากเว็บแคม
cd .. && streamlit run app.py                        # เว็บเดโม: อัปโหลดรูปหรือถ่ายจากกล้อง เลือกโมเดล รูปแบบบดบัง และ τ
```

- `webcam.py` ปุ่มลัด: `v` เปลี่ยนรูปแบบการบดบัง · `+` / `-` เพิ่ม/ลด τ · `s` บันทึกภาพ · `q` หรือ Esc ออก
- ขอบขวาของภาพวิดีโอใน `webcam.py` แสดงใบหน้าหลังจัดตำแหน่งและจำลองการบดบังแล้ว คือสิ่งที่โมเดลเห็นจริง ๆ
- ใช้โมเดลอื่นได้ด้วย `--model ../models/<ชื่อไฟล์>.joblib` เช่น `lfw+custom_M2+aug.joblib` (ชื่อไฟล์คือ `<ชุดข้อมูล>_<โมเดล>.joblib`)
- รูปที่มีหลายใบหน้าจะทายทุกใบหน้า และกรองกรอบที่ MTCNN ให้ความมั่นใจต่ำกว่า 0.95 ออก (กันกรอบหลอกในพื้นหลัง)

### ทำให้ระบบรู้จักสมาชิกกลุ่ม 5 คน

ถ่ายภาพสมาชิกแต่ละคนอย่างน้อย **2 รอบ** (คนละวัน คนละห้อง หรือคนละแสง) รอบละประมาณ 30–40 ภาพ เพื่อให้ step 3 มีรอบที่
โมเดลไม่เคยเห็นไว้ทดสอบ และถ่ายคนนอกกลุ่มอีก 2–3 คนด้วย `--stranger` เพื่อดูว่าคนแปลกหน้าถูกทายเป็นสมาชิกบ่อยแค่ไหน

```bash
cd src
python capture_faces.py --name Worasak                    # SPACE = เริ่ม/หยุดบันทึก, q = ออก  -> data/custom/Worasak/<วันที่>/
python capture_faces.py --name Worasak --session lamp     # รอบที่ 2 (เช่นแสงต่างกัน) ตั้งชื่อรอบเอง
python capture_faces.py --name Somchai --stranger         # คนนอกกลุ่ม -> data/unknown/Somchai/<วันที่>/
python step1_detect_align.py --dataset lfw+custom         # หรือ --dataset custom ถ้าใช้เฉพาะสมาชิกกลุ่ม
python step2_extract_features.py --dataset lfw+custom --augment 2
python step3_train_evaluate.py --dataset lfw+custom --fit-all
python webcam.py --model "../models/lfw+custom_M2+aug.joblib"
```

- ตั้งชื่อเป็นภาษาอังกฤษไม่มีเว้นวรรค เพราะชื่อโฟลเดอร์คือชื่อที่ OpenCV วาดบนหน้าจอ (วาดภาษาไทยไม่ได้)
- `capture_faces.py` กด SPACE เพื่อเริ่มบันทึก และบันทึกเฉพาะตอนที่เห็นใบหน้า **หนึ่งใบหน้า** อย่างน้อยทุก 0.5 วินาที (`--interval`)
  หยุดเองเมื่อครบ 30 ภาพ (ปรับด้วย `--count 40`) ขยับหน้าเล็กน้อย เข้าใกล้/ถอยห่างระหว่างถ่ายเพื่อให้ได้มุมที่หลากหลาย
- `--fit-all` เทรนโมเดลที่บันทึกใหม่ด้วยทุกภาพของทุกคนเพื่อใช้ในเดโมสด ส่วนตัวเลขความแม่นยำที่รายงานยังมาจากโมเดลที่เทรนด้วยชุดเทรน
  และทดสอบกับชุดทดสอบที่แยกไว้ อย่านำไฟล์โมเดลที่ได้จาก `--fit-all` ไปวัดความแม่นยำกับภาพชุดทดสอบ เพราะมันเคยเห็นภาพเหล่านั้นแล้ว

### ผลการทดลองบน LFW (62 คน, 2,063 ภาพ, ทดสอบ 30 %)

Accuracy (%) จาก [`results/metrics.json`](results/metrics.json):

| รูปแบบที่ใช้ทดสอบ | M0 | M1 | M2 | M3 | M4 |
|---|---:|---:|---:|---:|---:|
| ใบหน้าเต็ม | 59.5* | 99.7 | 99.8 | 99.8 | 99.7 |
| ครึ่งบน | 6.9* | 90.8 | 98.4 | 94.7 | 97.7 |
| ครึ่งล่าง | 4.0* | 36.7 | 85.1 | 60.9 | 88.7 |
| เฉพาะดวงตา | 2.4* | 44.6 | 91.1 | 69.1 | 93.2 |
| เฉพาะจมูก+ปาก | 1.1* | 36.7 | 89.3 | 55.4 | 91.6 |
| สวมหน้ากากอนามัย | 5.7* | 85.3 | 97.3 | 93.5 | 97.7 |
| สวมแว่นกันแดด | 6.6* | 77.9 | 94.8 | 89.0 | 97.7 |

- **T1** ผ่าน: M2 บนใบหน้าเต็มได้ 99.8 % (เป้า ≥ 95 %)
- **T2** ผ่าน: M2 สวมหน้ากาก 97.3 % และสวมแว่น 94.8 % (เป้า ≥ 85 %)
- **T3** ผ่าน: M1 ได้ต่ำสุด 36.7 % เท่ากันทั้ง "ครึ่งล่าง" และ "เฉพาะจมูก+ปาก" เมื่อเทรนเพิ่มด้วยภาพบางส่วน (M2) ดีขึ้น
  +48.5 และ +52.7 จุดตามลำดับ (เป้า ≥ +10 จุด)
- การเทรนด้วยภาพบางส่วนช่วยมาก: M1 → M2 และ M3 → M4 ดีขึ้นทุกรูปแบบที่ถูกบดบัง
- เมื่อเทรนด้วยภาพเต็มอย่างเดียว FaceNet (M3) ทนต่อการบดบังกว่า VGG-Face (M1) ทุกรูปแบบ ส่วนเมื่อเทรนด้วยภาพบางส่วนแล้ว
  M4 สูงกว่า M2 ใน 5 จาก 6 รูปแบบที่ถูกบดบัง (M2 สูงกว่าเฉพาะ "ครึ่งบน")

\* **ตัวเลขของ M0 (Eigenfaces + SVM) ในตารางนี้วัดด้วยวิธีเดิมที่ไม่ตรงกับคำทำนายจริงของ SVM** (ใช้ argmax ของ `predict_proba`
แบบ Platt scaling ซึ่งอาจขัดกับ `predict` ของ SVM เอง) ตอนนี้ step 3 แก้เป็นวัดด้วยค่า decision ของ SVM แล้ว ดังนั้นเมื่อรัน step 3
ใหม่ **คอลัมน์ M0 จะเปลี่ยน** ส่วน M1–M4 ไม่เปลี่ยน

ตารางนี้มาจากการรันครั้งแรกกับ LFW (ตรงกับสไลด์หน้า 14) ส่วนที่เพิ่มภายหลัง (ทดสอบกับคนแปลกหน้า, Data Augmentation, FEI)
ให้รันตามคำสั่งด้านบนแล้วดูผลใน `results/RESULTS.md` และ `results/figures/`

### คำศัพท์ที่ใช้บ่อย

| คำ | ความหมาย |
|---|---|
| Occlusion | การบดบังใบหน้า เช่น หน้ากาก แว่น หมวก |
| Closed-set identification | ระบุว่าเป็นใครใน "กลุ่มคนที่รู้จัก" เท่านั้น |
| Open-set / คนแปลกหน้า | คนที่ไม่อยู่ในกลุ่มที่รู้จัก ระบบควรตอบว่า "Unknown" |
| Alignment | จัดตำแหน่งใบหน้าให้ตา จมูก ปาก อยู่ตำแหน่งมาตรฐาน |
| Transfer Learning | ใช้โมเดลที่เทรนมาแล้ว แล้วเทรนต่อเฉพาะส่วนท้าย |
| Feature Extractor | ส่วนของโมเดลที่แปลงภาพเป็นเวกเตอร์คุณลักษณะ (ในงานนี้แช่แข็งน้ำหนักไว้) |
| Softmax | ชั้นจำแนกที่ให้ความน่าจะเป็นของแต่ละคน รวมกันเป็น 1 |
| τ (tau) | เกณฑ์ความมั่นใจขั้นต่ำ ถ้า p สูงสุดต่ำกว่าค่านี้ ตอบ "Unknown" |
| Stratified split | แบ่งชุดเทรน/ทดสอบโดยรักษาสัดส่วนภาพต่อคนให้เท่ากันทั้งสองฝั่ง |
| Session | การถ่ายภาพหนึ่งรอบ (วัน/ห้อง/แสงเดียวกัน) |
| Data Augmentation | สร้างสำเนาของภาพเทรนที่ถูกปรับแบบสุ่ม เพื่อเพิ่มความหลากหลายของข้อมูล |
